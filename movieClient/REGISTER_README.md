# 會員註冊功能說明

## 功能概述
已成功實現會員註冊功能，用戶可以從登入頁面點擊"點此註冊"連結進入註冊頁面。

## 實現的功能

### 前端功能
1. **註冊頁面** (`/register`)
   - 完整的會員資料表單
   - 必填欄位驗證
   - 密碼確認驗證
   - 性別下拉選單（男/女）
   - 生日日期選擇器
   - 個人簡介（可選）
   - 載入動畫
   - 成功後自動跳轉到登入頁面

2. **會員資料欄位**
   - 姓名（必填）
   - 電話（必填）
   - Email（必填）
   - 密碼（必填）
   - 確認密碼（必填）
   - 生日（必填）
   - 性別（必填，下拉選單）
   - 地址（必填）
   - 個人簡介（可選）

### 後端功能
1. **註冊API端點** (`POST /api/Members/Register`)
   - Email重複檢查
   - 自動設定預設值：
     - MemberRank = "C"
     - MemberPoint = "0"
   - MemberID自動生成（資料庫主鍵）
   - MemberBio可為null

2. **DTO類別**
   - `RegisterRequest.cs` - 註冊請求資料傳輸物件

## 使用方式

1. 在登入頁面點擊"點此註冊"連結
2. 填寫所有必填欄位
3. 選擇性別和生日
4. 點擊註冊按鈕
5. 註冊成功後會自動跳轉到登入頁面

## 技術實現

### 前端技術
- Vue 3 Composition API
- Vue Router
- Bootstrap CSS
- Fetch API

### 後端技術
- ASP.NET Core Web API
- Entity Framework Core
- C# DTO模式

## 路由配置
- `/login` - 登入頁面
- `/register` - 註冊頁面

## 注意事項
- 所有必填欄位都有標示紅色星號(*)
- 密碼需要輸入兩次確認
- Email不能重複註冊
- 註冊成功後會顯示成功訊息並自動跳轉
